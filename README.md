# Basar Tischbörse

MVP für eine kostenlose Basar-Tischreservierungsplattform.

## Buchungsregeln
- 1 Tisch: 12 €
- 2 Tische: 20 €
- 3 Tische: 25 €
- Kuchenspende: -4 € vom jeweiligen Gesamtpreis
- Angebot: Kinder **oder** Erwachsene
- Für Kinder + Erwachsene sind zwei getrennte Buchungen erforderlich.
- Maximal verfügbare Tische werden pro Basar hinterlegt.
- Buchungen dürfen die verfügbare Tischzahl nicht überschreiten.

## MVP
Die aktuelle Demo ist vollständig lokal nutzbar und speichert Testbuchungen im Browser. Für den echten Onlinebetrieb werden Datenbank, E-Mail, PayPal und PDF-Erstellung angeschlossen.
